# Enterprise Network Design
This project simulates a small-to-medium enterprise network using Cisco Packet Tracer. The network supports multiple departments, dedicated server infrastructure, and Internet connectivity. The design incorporates routing, switching, IP addressing, and network segmentation principles to provide secure and scalable communication between resources.
## Features
- Multi-floor network architecture
- Departmental network segmentation
- Dedicated server subnet
- wired client support
- Internet connectivity
- Routing and switching infrastructure
- Scalable enterprise network design
